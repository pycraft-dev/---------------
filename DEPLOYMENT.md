# Деплой для доступа с телефона

## Streamlit Community Cloud

1. Откройте `https://share.streamlit.io/` и войдите через GitHub.
2. Нажмите **Create app**.
3. Выберите репозиторий Telegram-парсера, ветку `main` и файл `app.py`.
4. Нажмите **Deploy** и дождитесь статуса **Running**.
5. Откройте выданный URL на телефоне. Для приватного доступа включите авторизацию в настройках приложения.

Приложение не использует секреты для запуска. Файл `.env` остаётся локальным и исключён из Git.

## Ограничение хранения

На Streamlit Community Cloud локальный SQLite-файл может быть удалён при перезапуске или пересборке. Для постоянной истории подключите внешнюю SQLite/PostgreSQL-базу и задайте `DATABASE_PATH` через Secrets/переменные окружения.

## Альтернатива для постоянного процесса

На VPS запустите UI командой `streamlit run app.py --server.address 0.0.0.0` за reverse proxy с HTTPS. Сборщик запускается отдельно: `python collector.py`.
